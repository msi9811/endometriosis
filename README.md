# (제목) Endometriosis Microbiome & Transcriptomic Analysis

> (상태 안내) **Note:** This repository contains the source code to reproduce the analyses for our manuscript (currently under review).

---

## (섹션 1: 필수 파일) Required Data Files

(설명) To run the analysis scripts in this repository, the following three data files are required. Please ensure they are placed in your working directory before executing the code.

| File Name | Description | Availability |
| :--- | :--- | :--- |
| **`mb_matrix.csv`** | (설명) Matrix data used for the transcriptomic analysis. | (경로) **Available directly in this repository** |
| **`immune_estimation_epic.xlsx`** | (설명) Immune cell fraction estimation values generated using the EPIC algorithm based on transcriptomic data. | (경로) **Available directly in this repository** |
| **`supplementary_table.xlsx`** | (설명) Supplementary metadata and summary tables required for the analysis. | (경로) **Accessible via the Supplementary Material of the forthcoming published article** |

---

## (섹션 2: 사용법) Usage

1. (단계 1) Clone this repository and download `mb_matrix.csv` and `immune_estimation_epic.xlsx`.
2. (단계 2) Obtain `supplementary_table.xlsx` from the Supplementary Material upon publication and place all three files in the same working directory.
3. (단계 3) Run the analysis scripts sequentially.
